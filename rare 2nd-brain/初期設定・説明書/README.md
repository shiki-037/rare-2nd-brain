# 稀な第二の脳

このリポジトリは、シキのAI活用・制作・調査・知識管理に関する情報を保存・整理するための場所です。

## 目的

AIを活用した調査、情報整理、コンテンツ制作、知識の蓄積を行い、必要な情報をいつでも再利用できる状態にします。

## 主な役割

- AI活用に関する情報の保存
- 調査した情報や資料の整理
- note・Xなどのコンテンツ制作に関する資料の管理
- Claude CodeなどのAIツールに関する設定・資料の管理
- Obsidianなどで管理する知識のバックアップ
- AIを使った制作環境の記録
- 作業内容や設定変更の履歴を保存

## AIとの連携

このリポジトリに保存されているファイルは、AIを使った調査・制作・整理を行う際の参考資料として使用します。

AIがファイルの内容を扱う場合は、実際に保存されている情報を確認し、内容を勝手に変更・推測・創作しないことを基本とします。

情報が不足している場合は、不足していることを明確に伝えます。

## 基本方針

- わからないことを推測で断定しない
- 事実と推測を区別する
- 重要な情報は元の資料を確認する
- ファイルを変更・削除する場合は、内容を確認してから行う
- 必要のないファイルを勝手に削除しない
- 重要な設定や資料を勝手に変更しない
- 作業はできるだけシンプルに行う
- 新しい情報を追加するときは、既存の構成を確認してから追加する

## ファイルについて

このリポジトリ内の各ファイルは、それぞれの目的に応じて管理します。

設定・指示書・資料などの重要なファイルについては、ファイル名から役割が分かるように整理します。

## 更新方針

このリポジトリは、AIを使った調査・制作・知識管理の環境が成長するにつれて更新していきます。

新しい仕組みを追加するときは、既存の構成を確認し、できるだけシンプルで分かりやすい形を維持します。
