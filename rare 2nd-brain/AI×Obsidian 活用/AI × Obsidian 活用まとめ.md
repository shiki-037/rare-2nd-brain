## 1. この保管庫の目的

この保管庫は、シキのAI活用・制作・調査・知識管理に関する情報を保存・整理するための場所です。

AIを活用した調査、情報整理、コンテンツ制作、知識の蓄積を行い、必要な情報をいつでも再利用できる状態にすることを目的としています。

## 2. AIとObsidianで行っていること

- AI活用に関する情報を保存する
- 調査した情報や資料を整理する
- note・Xなどのコンテンツ制作に関する資料を管理する
- Claude CodeなどのAIツールに関する設定・資料を管理する
- Obsidianなどで管理する知識をバックアップする
- AIを使った制作環境を記録する
- 作業内容や設定変更の履歴を保存する
- AIを使って情報を整理し、知識を蓄積する方法を検証する
- 既存ノートの検索と読み取りを行う
- 新規ノート作成を確認する

## 3. 連携しているAI・サービス

保管庫内で名前が確認できるAI・サービスは以下です。

- Obsidian
- ChatGPT
- Claude Code

- NotebookLM
- GitHub
- Git
- note
- X

## 4. Obsidianを第二の脳として使う考え方

Obsidianはシキの「第二の脳」として扱います。

Obsidianに保存されている情報を整理・検索・関連付けし、知識を蓄積していくことを重視します。

また、Obsidianを第二の脳として使い、Gemini NotebookやClaude Code、GitHubなどと連携することで、AIを使った情報整理と知識管理を効率化できると書かれています。

## 5. 今後の活用

保管庫内に明確に書かれている今後の活用は以下です。

- AIを使った調査・制作・知識管理の環境が成長するにつれて、この保管庫を更新していく
- 新しい仕組みを追加するときは、既存の構成を確認する
- できるだけシンプルで分かりやすい形を維持する
- AIによる新規ノート作成を確認する
- GitHubを使ったファイル管理に活用する
